# Obsidian PARA Vault (Chained Project Templates)

- **PARA**: `00_inbox/`, `projects/`, `areas/`, `resources/`, `archive/`
- **Chained Deliverables**: Each *phase* note lists its `inputs` and `outputs` in frontmatter.
- Use the files under `templates/` to create new projects; copy `_template` and rename the folder.
- Start from `dashboard.md` as your home.
- Dataview and Tasks plugins are recommended.
