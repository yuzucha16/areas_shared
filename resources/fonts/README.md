# fonts

端末にインストールするフォントの置き場。ファイルはGit LFSで管理する（`.gitattributes` 参照）。

## 置くもの

- HackGen Console NF Regular（`HackGenConsoleNF-Regular.ttf`）
  - 入手元: <https://github.com/yuimarudev/hackgen>（Nerd Fonts 版の配布物）
  - 版: （コミット時に記入）
  - ライセンス文書: 配布物に付属するライセンスファイルを、同じディレクトリに置く（例: `LICENSE-HackGen.txt`）。再配布条件は配布元で確認する（未確認）。

## 使っている場所

`HackGen Console NF` は VS Code・Windows Terminal・Notepad++・Obsidian の設定が参照している（dotfiles の `windows/` 配下）。
